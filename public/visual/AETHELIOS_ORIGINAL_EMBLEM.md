# Aethelios original emblem — Live globe only

Founder-supplied 1254×1254 RGBA original of the gold ascending A and compass star. Live hosts this file for the call globe. It is not an install icon and does not replace `public/brand/aethelios-official-20261015-*`.

The plate has a real alpha channel and no wordmark. Geometry is not redrawn, not font-substituted, and not cropped to a rounded-square app tile. Other routes keep their existing crest, lockup and install artwork.
