# Imperial Emerald II — Living Emerald Architecture

Implementation candidate, October 12, 2026. Canonical repository only. Base: `fd49ba4` (released Intelligence Motion #106). Branch: `codex/imperial-emerald-ii`. No production deployment, merge, migration, configuration change or provider activation.

## Audit and implementation

Next.js 16.3.5 App Router / React 19.3 modular monolith, Node 24, Tailwind 4 with PostCSS. Server routes/services own identity, session authorization and persistence; interactive components own transient state. The five primary environments remain Talk, Work, Studio, Lifestyle and Ecosystem. Reconciliation preserves the newly released Health destination as well. Public/member Lifestyle share merchant-backed components. Founder Office is account-authorized within the member shell.

The existing color source is `src/platform/visual/aether-palette.json`, generated by `scripts/generate-aether-tokens.mjs` into `aether-tokens.css`. `imperial-workspace.css` provides shared io semantic roles. Many historical CSS layers remain compatibility contracts; this pass adds one bounded, last-imported refinement stylesheet rather than reorganizing routes or rewriting those layers. Existing local Inter/Sora and editorial Georgia remain. Native dialogs own keyboard focus/Escape. Markdown rendering owns message typography; Next Image owns merchant imagery. Existing GSAP/Three/WebGL intelligence motion is preserved; no new visual libraries or animation loops.

- **Foundation/shared shell:** requested obsidian #070B0A, forest #102A24, imperial #163F35, illuminated #245B48, ivory #E8E9E2, sage #9AAFA5 and champagne #D6B76A. Gold remains #C4912F. Semantic reading, navigation, floating, focus, selection, warning, danger and success roles retain distinct meaning. Static Satin Forest, Living Emerald and Gilded Obsidian gradients replace repeated material values through existing contracts. Existing navigation width/collapse and all five links remain; selection, pointer feedback and focus are refined.
- **Talk:** concise welcome, recognizable static existing-orb fallback with orbital detail, responsive suggestions, separate new/active classes, readable long responses and heading spacing, quiet but reachable 44px message actions, distinct user message plane and unified satin composer focus. Composer handlers, sizing/visual viewport, send/voice/attachments, history, naming, streaming, save/recovery, context consent and drafts are unchanged. Existing request/Live presence remains separate. No new WebGL context runs in the welcome identity.
- **Work / Founder Office:** restrained command surface and a read-only “What needs your attention?” index before the existing preparation form. Groups show pending company approval requests, prepared/ready assigned work, recorded gaps/blocked tasks/approved actions awaiting an executor, and review/interruption/history-repair needs. All links lead to existing company mission workflows. Groups can overlap and explicitly describe the bounded snapshot; no background activity, progress percentages, inferred changes or fabricated counts. Daily/personal approvals stay in their existing separate approval center. Empty company states are explicit. No requests, writes or execution controls are added by the index.
- **Studio:** editorial heading, Living Emerald Direction and satin project navigation; media/reading canvas stays obsidian. Existing conditional specialist rooms and creation/recovery/delivery workflows remain.
- **Lifestyle:** shared emerald editorial hero and satin brand surfaces, consistent title/price typography and wrapping. Merchant inventory, images, prices, availability, cart, checkout and Shopify logic are untouched.
- **Ecosystem:** an emphasized Intelligence plane within the existing connected division composition. Existing destinations, planned-offer labels and unavailable-service copy remain.
- **Responsive/accessibility:** retain existing 1100px shell collapse and five-destination compact navigation. Attention index uses four/two/one columns at available widths; Talk suggestions stack below 700px, and the welcome orb gives space back in short viewports. Existing dynamic viewport/safe-area/keyboard handling, native dialogs, Still, solid surfaces, increased contrast and forced colors remain. Reduced motion disables added interaction transitions. Featured secondary text is #C1CEC5 because sage alone measures 3.40:1 on illuminated emerald; featured secondary measures 4.84:1. Ordinary sage on imperial emerald measures 5.04:1. Token measurements are not a whole-page WCAG claim.
