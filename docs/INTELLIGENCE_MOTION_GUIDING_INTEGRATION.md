# Guiding-aperture integration candidate

October 12, 2026. Founder requested research and execution of the next build phase. The recommended aperture study is used as a working candidate; this does not record final creative approval or a production release.

## Research applied

[Animade’s Meta AI case study](https://archive.animade.tv/work/meta-ai-ring) describes a brand-derived object and inward listening/outward responding. Aethelios uses its own circular boundary, emerald material, precise gold aperture and four-point focus rather than copying Meta’s ring. Voice uses only existing measured envelope levels, never pitch or fabricated syllables.

[web.dev’s animation engineering guide](https://web.dev/articles/animations-guide) recommends transform/opacity and actual rendering inspection. This candidate uses those properties for movement, no new dependency and no GPU context. SVG compositing cost remains a measurement gate, not an assumed performance pass.

Native Live transport, phase mapping, audio measurement subscription, permissions, consent, background jobs, cleanup, interruptions and mode switching are unchanged. This visual candidate removes the operational Live orb’s shader mount in favor of the shared vector identity. No shader-resource recreation on phase updates, new provider, schema, credential, activation flag or hosted configuration change occurs.
