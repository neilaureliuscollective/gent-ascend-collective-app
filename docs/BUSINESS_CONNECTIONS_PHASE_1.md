# Connected Business — Phase 1

Implements Public Aethelios as the existing intelligence engine and Reserve as the authoritative business system. Separate confirmed accounts use Reserve Supabase's managed OAuth code flow with S256 PKCE and a confidential Public client. Native OAuth scopes are identity scopes, not business authority. An explicit 30-day provider grant additionally binds the Reserve user, OAuth client and hashed connection nonce. Every delegated read verifies a live Auth user, issuer/subject/client/expiry claims, DB capability overrides and provider assignment. Only a dedicated appointment projection crosses the boundary; no client names/contact records, Chair information, private notes, personal routines or financial records. Maximum seven local-time days and 50 appointments per page.

Public stores AES-256-GCM credentials server-side, with owner+connection AAD and atomic refresh leases. Its owner-visible tables never contain tokens. Refresh uncertainty requires reconnect; disconnect cannot resurrect an old lease. The existing personal/Company Talk pipeline, quotas and persistence are reused. Per-reply model consent and server-only source receipts retain provenance. Existing Studio AI is server-blocked for actively connected professionals; its launcher opens Public when its configured HTTPS destination is present.
