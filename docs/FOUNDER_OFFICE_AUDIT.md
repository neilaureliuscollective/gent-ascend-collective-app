## Status definitions

1. **Verified functional**: directly observed against a real connected service during this inspection. The exact observation is stated; metadata does not prove a browser journey.
2. **Implemented but not live-verified**: source and relevant automated checks exist; authenticated/provider/device acceptance is unverified here.
3. **Partial or defective**: a useful component exists but a material function, integration or acceptance gate is missing or fails.
4. **Missing**: no operating implementation in the inspected target. Pending PR descriptions are not production acceptance.
