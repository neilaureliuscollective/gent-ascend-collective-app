## Data and lifecycle

architect_origin_versions: immutable snapshot, request UUID, revision, change note, compound owner/project FK.
architect_origin_runs: owner-scoped exploration/proposal receipt, input, exact base revision, bounded result and status. Compound owner/project FK. A shared AI conversation uses the project UUID so conversation text can be opened in Talk; Talk deletion does not erase Origin records. No project data is automatically global memory.

All table writes are revoked from ordinary clients; SELECT RLS checks persons.auth_user_id. Narrow owner-derived functions with empty search_path serialize writes, enforce replay payload equality, stale revision rejection, project/version ceilings and history immutability. AI run reservation never changes approved content. Approve/edit a proposal then explicitly save a revision. Historical restoration creates a new revision. Documents carry draft/approved status and the blueprint revision on which they were based.
