## Implemented

- Footage room inside existing Obsidian Studio: bounded brief, landscape/portrait, fresh reviewed estimate, explicit one-render approval; edits clear quote and consent. Film brief can be exported with integration inactive. Synthetic media and external provider transfer are disclosed.
- Owner/project saved quotes and jobs with immutable request IDs. Server HMAC covers every quote field, owner, project, cost policy and expiration. Separate HMAC binds provider task to owner and internal job. Direct authenticated RPCs cannot use forged provider IDs to get another customer's outputs via the server key. Signatures are integrity controls in addition to session-bound RLS, not a substitute for Auth.
- Atomic pilot reservations: one active submission/person, at most three attempts and 180 reserved credits per rolling day. Usage survives project deletion. Failed/unknown attempts keep allowance; provider refunds are never inferred. Paid POST runs once after reservation; duplicate/replayed starts read existing receipt. Timeouts, malformed/failed submission responses and unknown acknowledgements are uncertain, never auto-retried. Known provider receipt writes can be retried identically; paid generation cannot.
- Explicit Check render status uses signed task identity and a three-minute save lease, with 15-second spacing after ordinary queued checks. No fake completion percentage, worker, cron, webhook, hidden polling or auto-publishing. User must return and check jobs promptly. Pending vendor status remains submitted. Failed/cancelled receipt is reported honestly.
- Completed clips are validated as bounded MP4 containers: real movie header/duration, track dimensions, media payload, finite parsing/depth/count limits, maximum 30 MB. Validation is not a full decoder or moderation scan; browser/live playback acceptance remains necessary.
- Separate private `aethelios-studio-video` bucket. Exact Auth-user/project/job paths, owner-only stream, no-store, byte-range playback and MP4 downloads. A completed provider task is not labeled saved until private copy and receipt commit. Ambiguous upload/ack failures recover from original private bytes on the next check, without deleting files or rendering again. Network/permission errors are not treated as absence.

Leaving the room does not cancel a paid render. Provider DELETE cancels pending/running tasks but deletes completed tasks; a race could destroy output. No cancellation is exposed in this pilot. Text-only standalone clips are implemented; owned image-to-video, campaign timeline integration, clip trimming/compositing, automatic preservation and soundtrack mixing remain future work. Existing image/native Campaign/narration flows stay intact.
