## Plan and delivered behavior

1. **See the ritual before entering.** A collapsed preview shows exact step and linked-product counts; expansion reads the saved sequence.
2. **Choose the pace.** Guided and All steps views use the same routine. Select a saved step to return directly to it. Navigation never records completion; explicit recording retains the existing daily/version/request guards.
3. **Arrange the routine.** Optional individual-step editing supports moving, removing and adding steps alongside the existing text editor. Keyboard focus follows the moved or added step; announcements describe changes. The exact newline contract and 1,000-character budget remain canonical. Review shows before/after step counts, existing-version comparison and explicit saving.
4. **Close the feedback loop.** A confirmed feedback receipt refreshes the chamber's private week data. Progress counts days with recorded practice and recorded rituals, plus exact predefined effort/irritation choices. Those observations invite review of the explicitly named selected ritual. Cross-ritual notes are never attributed to that ritual or interpreted as a product cause. Opening the editor does not alter the routine.

The existing obsidian, green and gold materials, fullscreen sheets, touch targets and forced-color support are extended. The simple daily path keeps its existing number of required actions. Arrangement and progress review are optional.
