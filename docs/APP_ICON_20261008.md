# Public Aethelios official mobile icon — October 8, 2026

Founder explicitly authorized recreation, implementation and production deployment. Canonical repository: `neilaureliuscollective/gent-ascend-collective-app`; live custom domain: `www.gentascend.com`. Private Aethelios is excluded.

## Artwork and reproducibility

Built-in image generation recreated the attached approved crest: sculpted gold A, symmetrical laurels, concentric circular gold crest, celestial stars/beads, and deep imperial teal-blue texture. The technical change extends the background to every canvas edge, removing the photographed-icon exterior, black corners and drop shadow. No wordmark, replacement glyph or new logo concept. The recreation is faithful rather than pixel-identical.

Master: `public/brand/aethelios-app-20261008-master.png`, 1024×1024 opaque RGB. `node scripts/current-app-icons.mjs` produces opaque 192/512 standard PWA, 192/512 maskable, 180 Apple, 64 browser, 16/32 PNG favicon and 16/32/48 multi-resolution ICO assets. Lanczos resizing preserves proportions. Maskable artwork is 80% scale so the circular crest, A, laurels and cardinal stars stay inside the central 80%-diameter safe circle; the outer ornamental square frame is decorative and may be clipped. Surround uses the master's blue corner texture with feathered edges, not black padding. Round-mask preview inspected locally.

## Configuration and caching

Manifest keeps stable `id: /`, root scope, standalone mode, `/app` start URL and existing shortcuts. Only icon URLs change. Next.js file-based Apple/browser assets emit content-hashed metadata; favicon.ico uses the same art. Legacy icon/icon-v2 installation redirects and Apple touch aliases point to current assets. Original archived crest assets and the in-app brand identity remain intact.

Service-worker static fallback cache advances v4→v5 and precaches the new 192px asset. Existing scoped old-cache cleanup, private network-only behavior, other caches and unsaved workspace preservation remain intact. Manifest and service-worker no-cache headers already exist.
