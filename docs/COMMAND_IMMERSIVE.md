# Command elevation · 2026-10-04

## Inspected foundation and pressure test

The existing arrive → choose → act → reflect loop puts profile setup, goal setup, intention, energy, sleep, actions, action completion, reflection and evening review on the opening surface. DailyData, versioned daily RPCs, ownership/RLS, saved conversations, confirmed reviews and Capture remain useful. Preserve them beneath a lazy day workspace; no schema replacement or autonomous model call.

The opening is now Moment → connected saved context → one next move → Needs you → In motion → Depth. Safe projection is automatic. Intention is optional contextual briefing, not an opening form. Energy/sleep become inspectable self-reports with missing-day gaps. Actions, completion, reflection and review remain deeper. Profile/goals are navigation rather than mandatory onboarding. No background agent, fabricated health inference, automatic memory ingestion or nonexistent integration.

Aethelios uses the existing bounded, deferred renderer. Graph edges connect available saved records to the briefing, not inferred causal links between health, goals and actions. Daily actions have no goal relationship in the contract; do not draw one. Existing context authorization is unchanged. The scene receives only presentation state; record text remains accessible HTML.

## Responsive and autonomy boundaries

Phone: greeting and saved direction before a compact central Orb; signals occupy upper/lower corners, one next move below, visible in the opening viewport. Short phone reduces scene height and optional source captions; source remains available on selection. Unfolded/tablet/desktop spread signal positions around the central environment, not a widget grid. Large text reflows; source detail is normal document flow. Keyboard selection uses real buttons and native disclosure. No pointer/hover-only information.

AUTO: assemble authorized saved records. INFORM: quietly expose retained context. APPROVE: suggested actions, priority/memory changes, external work. Unknown or unauthorized operations denied. Classifier is an extension seam, not an executor; existing server authorization/RPCs remain decisive. Needs You uses real pending proposals oldest-first, approval/rejection with saved-state refresh and uncertainty lock/reload.

## Budget and sequence

No dependencies, video, textures, second scene, postprocessing, per-frame React state or private model calls. Initial JS target no more than 10KB over baseline; deferred shared Three measured separately. Max one canvas; existing cap480px/DPR1.5 and adaptive fallback retained. Static rendering must remain complete.

Sequence: preserve rich workspace → deterministic server opening projection → signal field and source inspection → bounded optional Orb → real decision adapter → responsive/reduced-motion/keyboard checks → payload comparison. Validation results recorded in STATUS.md. Physical foldable/GPU/battery and real Supabase identity/persistence must be distinguished from browser fixtures.
